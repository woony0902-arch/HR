# 용어 정리 — 에이전트·대시보드에서 쓰는 말

기준: HR실장과 HR 담당자가 설명 없이 읽을 수 있는가. 회사에서 이미 쓰는 말(보임, 직책자, 담당, 국사)은 그대로 두고,
분석 용어에서 온 말(span, lineage, ledger, delta)은 우리말로 바꿨다. 데이터 키·규칙 문자열(`max_span=15`)은 기계용이라 그대로다.

## 바꾼 것 (2026-09 적용)

| 이전 | 지금 | 이유 |
|---|---|---|
| 조직 **승계**, 승계 검토, 승계처, 승계 비율 | 조직 **계보**, 계보 검토, 이어진 조직, 이어진 인원 비율 | HR에서 승계는 사람의 후계(승계 계획)를 뜻한다. 같은 화면에 정년·후계 지표가 있어 두 뜻이 충돌했다. 조직이 전년에서 올해로 이어지는 것은 계보로 부른다. |
| 승계 리스크 높은 팀 | 후계(사람 승계) 공백 위험 팀 | 위와 같은 충돌을 반대쪽에서 정리. 도구 설명에만 있고 화면에는 아직 없다. |
| 중위 span, 최대 span, span 초과 | 중위 관리 폭, 최대 관리 폭, 관리 폭 초과 | span of control 은 조직론 용어. 임원에게는 관리 폭(팀장 한 명이 직접 관리하는 인원)이 바로 읽힌다. |
| Before / After / Δ, 구조델타 | 현재 / 개편 후 / 증감, 구조변화 | 표 머리글이 영문·기호라 눈에 걸렸다. |
| 기계 판정 | 자동 분류 | "판정"은 사람이 원장에 남기는 것이므로 기계 결과를 판정이라 부르지 않는다. |
| 판정 원장·지침 원장 (대시보드 카드) | 지침 / 판정 / 현업 의견 (원장 구역 안 세 카드) | 원장이라는 큰 묶음 아래 세 종류를 나란히 둔다. |
| 지침 입력 (메뉴) | 지침 관리 | 등록만이 아니라 수정·철회·삭제가 생겼다. |
| 판정 kind "구조" (계보 판정) | "계보" | 계보 검토에서 남기는 판정의 종류 이름. 이미 기록된 "구조" 항목은 그대로 보인다. |

## 그대로 둔 것과 이유

| 용어 | 뜻 | 둔 이유 |
|---|---|---|
| 원장 | 판정·지침·현업 의견이 쌓이는 기록부. 시뮬레이션과 대시보드가 이것을 읽는다 | "기록"보다 강한 말이 필요했다. 한 번 남기면 다음 논의의 전제가 된다는 뜻. 어색하면 "기록부"로 바꾸면 되고 코드 영향은 없다 |
| 작업판 | 대화 오른쪽, 모델 없이 즉시 계산하는 패널 | 대안 "작업 패널"과 큰 차이 없음 |
| 판정 | 사람이 내린 결정(유지·통합검토·R&R재정의·명칭변경·보류) | 기계는 분류하고 사람은 판정한다는 구분을 유지 |
| 지침 | 그룹·모회사·경영진·HR실장·시장환경·규제에서 온 전제. 규칙(기계 검사)/방향(해설 우선순위)/전제(배경) | 실장이 쓰는 말 그대로 |
| 현업 의견 | 개편 대상 조직(팀·담당·본부)에 붙은 입장: 찬성·조건부·반대·보류. 사실이 아니라 입장이며 출처(역할)와 함께 인용 | 새로 추가 |
| 미확인 / 확인됨 / 만료 / 철회 | 지침 상태. 구두 지침은 미확인으로 시작 | 상태 네 개면 충분 |
| 보임 해제 | 통합·폐지로 팀장 자리가 사라지는 수 | 회사 용어 |
| 직책자, 직책자 비율 | 보임 플래그 Y 인 인원과 그 비율 | 회사 용어 |
| 병렬 조직군 | 지역·채널로 나뉘어 같은 기능을 하는 팀들(영업팀·운용팀·구축팀) | 대안 "지역 병렬 조직"은 채널 분할을 놓친다 |
| 기능 중복 후보 | R&R 유사도가 높은 팀 쌍. 병렬 조직군 제외 | 후보라는 말이 "아직 판정 전"을 담는다 |
| 미션 커버율 | 담당이 선언한 R&R 중 하위 팀이 맡고 있는 비율 | 담당 R&R 문서의 첫 열이 "미션" |
| 소규모 팀 / 과대 팀 | 기준 인원 미만 / 20명 초과 | 임원 어휘와 맞음 |
| 5년 내 정년 | 정년(60세)까지 5년 이내 | 회사 정년 기준 그대로 |

## 아직 결정이 필요한 것

- **원장**을 그대로 쓸지 **기록부**로 바꿀지 — 실장 반응 보고 결정.
- 판정 종류 이름(중복후보·병렬조직군·조직명·계보)이 실장 어휘와 맞는지.
- 지침 출처 목록(그룹·모회사·CEO·경영진·HR실장·시장환경·규제)에 빠진 곳이 있는지 — 예: 노조, 감사.
- 현업 의견 방식(회의·메일·구두)에 "공식 회신"이 필요한지.
