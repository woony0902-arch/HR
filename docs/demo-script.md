# 실장님 시연 대본 — 에이전트 v0

## 목적
에이전트의 **행동 방식**에 대한 피드백을 받는다. 숫자의 정확도가 아니다.
기능 분류 사전이 시드 상태라 기능 지도 수치는 아직 믿을 수 없고, 그 사실을 시연 중에 말한다.

## 준비
```bash
export ANTHROPIC_API_KEY=...
python3 agent.py                  # 실제 데이터 (보안 확인 후)
python3 agent.py --data data_demo --ledger data_demo/ledger/decisions.csv   # 합성 데이터 (보안 확인 전)
```
보안 확인 전이면 **합성 데이터로 행동을 보여주고, 실제 데이터 결과는 로컬 리포트(`output/01_진단리포트.md`)로 따로 보여준다.**
모델에는 팀 단위 집계와 R&R 문장만 전달되고 사번·나이·성별·입사일은 코드 수준에서 차단된다 — 이 점을 먼저 설명한다.

## 시연 순서 (약 25분)

### 1. 되묻기 — 조직명을 지어내지 않는다 (2분)
> **나>** 구축팀 상황 알려줘

기대: 6개 후보를 나열하고 어느 것인지 되묻는다. "인사기획팀"처럼 없는 이름을 넣으면 없다고 하고 비슷한 조직을 제안한다.
**보여줄 것**: 모델이 조직을 추측하지 않는 구조.

### 2. 계산·가정·판단의 분리 (4분)
> **나>** 대구구축팀 현황

기대: 인원·연령·5년내 정년·R&R·3개년 이력을 말하고, **"지역은 조직명에서 추론"**, **"이력은 구성원 이동으로 추정"**이라는 가정을 붙인다.
**보여줄 것**: 모든 답에 가정이 따라온다. 틀린 가정이 있으면 그 자리에서 고칠 수 있다.

### 3. 시뮬레이션 — 누적 편집 (6분)
> **나>** 대구랑 부산 구축팀을 합치면 어떻게 돼?
> **나>** 거기에 서부구축팀도 넣어봐

기대: 두 번째 질문에서 개편안이 **덧붙여진다.** 결과에 지역 간 통합 경고("사람은 원래 자리에 남는다"), span 초과(출처 GRP-02), 만들어진 조직의 5년 내 정년율이 나온다. "통합해야 한다"고 말하지 않는다.
**보여줄 것**: 개편이 무엇을 바꾸는지는 계산되지만, 좋은지는 판단하지 않는다.

### 4. 판정 원장 — 판단을 건져 올린다 (4분)
> **나>** 구축팀은 국사 때문에 합칠 수 없어. 그대로 둬야 해.

기대: "이렇게 기록할까요? 대상 구축팀 군 / 판정 유지 / 사유 국사 위치로 인력 집중 불가"라고 **확인을 먼저 구한다.** 동의하면 기록. 이후 같은 통합안을 시도하면 기존 판정을 먼저 알린다.
**보여줄 것**: 내년에 같은 논쟁을 반복하지 않는 장치.

### 5. 지침 원장 — 임원만 아는 전제 (4분)
> **나>** 그룹에서 올해 팀장 자리는 늘리지 말라고 구두로 내려왔어

기대: 출처(그룹·구두), 규칙인지 방향인지, 검사 조건이 있는지 묻고 구조화해서 확인을 구한다. 기록되면 **미확인** 상태이며, 이후 시뮬레이션 제약 검사에 반영된다.
**보여줄 것**: 지금까지 임원 머릿속에만 있던 전제가 처음으로 기록되어 HR과 공유된다.

### 6. 범위 밖 (1분)
> **나>** 그 팀 팀장 누가 제일 나아?

기대: 개인 평가는 범위 밖이라고 답한다.
**보여줄 것**: 하지 않는 일이 명문화되어 있다.

## 피드백 질문 — 이 순서로 묻는다

1. **되묻는 빈도가 적절한가?** 너무 자주 묻는가, 아니면 추측했으면 하는 지점이 있는가?
2. **가정을 매번 붙이는 것이 도움이 되는가, 소음인가?** 어떤 가정은 한 번만 말하면 되는가?
3. **"판단하지 않는다"가 답답한가?** 어느 지점에서는 에이전트의 의견을 듣고 싶은가?
4. **판정 원장에 판정자 이름이 남는 것**에 대해 — 기록의 주체를 누구로 할 것인가?
5. **지침 원장** — 실장님이 알고 있는 그룹·경영진 지침 중 지금 넣을 수 있는 것이 있는가? 문서인가 구두인가?
6. **첫 화면에서 무엇을 먼저 보고 싶은가?** 중복 후보인가, 정년 절벽인가, 미션 정합성인가?
7. **기능 분류 사전** — 이것을 확정하는 세션을 잡을 수 있는가? (v1의 최대 병목)
8. **임원에게 이 도구를 보여준다면** 어떤 본부장부터, 어떤 질문으로 시작하겠는가?

## 시연에서 솔직하게 말할 것
- 기능 지도의 수치는 사전이 시드라 과다 집계되어 있다 (예: 안전환경 37팀)
- 지역은 조직명에서 추론한 것이라 근무지 데이터가 필요하다
- 대화 루프는 API 키가 없는 환경에서 만들어 실제 호출은 시연 직전에 처음 검증된다 — 첫 시연 전에 혼자 한 번 돌려본다
- 배포 환경(외부 LLM 전송 가능 여부)은 미정이며, 그래서 데이터 경계를 코드로 그어 두었다
